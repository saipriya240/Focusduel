⚡ FocusDuel

LOCK IN. SHOW UP. WIN.

FocusDuel is a gamified productivity application designed to make deep work more engaging through competitive focus sessions, productivity tracking, and social accountability.

Instead of fighting distractions alone, FocusDuel lets users turn productivity into a challenge.

✨ Features

- Focus Room: Dedicated space for focused work sessions.
- Focus Battles: Competitive 1v1 productivity challenges.
- Pomodoro Timer: Structured focus and break sessions.
- Leaderboard: Compare productivity and compete with others.
- Friends: Connect with friends and participate in challenges.
- Hall of Shame: A playful accountability experience.
- Analytics: View productivity activity and progress.
- User Authentication: Registration, login, and account management.

Note: Feature availability depends on the current implementation.

🛠️ Tech Stack

- React
- JavaScript (JSX)
- Vite
- Tailwind CSS
- Base44 backend services

🚀 Getting Started

Prerequisites

- Node.js
- npm

Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/focusduel.git

Navigate to the project:

cd focusduel

Install dependencies:

npm install

Configure the environment variables required by your Base44 project.

Start the development server:

npm run dev
